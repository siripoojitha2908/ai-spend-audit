# Pricing Data

AI Spend Audit includes pricing benchmarks for the following tools:

- Cursor: Hobby, Pro, Business, Enterprise
- GitHub Copilot: Individual, Business, Enterprise
- Claude: Free, Pro, Max, Team, Enterprise, API Direct
- ChatGPT: Plus, Team, Enterprise, API Direct
- Anthropic: API Direct
- OpenAI: API Direct
- Gemini: Pro, Ultra, API
- Windsurf: Starter, Growth, Scale

## Pricing model assumptions

- Desktop plans use per-seat pricing and team size thresholds.
- API Direct plans use per-seat or notional monthly spend approximations.
- The audit engine uses same-vendor downgrades and alternative vendor responses to identify overspend.
